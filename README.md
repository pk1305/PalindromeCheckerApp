# Palindrome Checker App (Java)

## 📌 Overview
A simple console-based Java application that checks whether a given string is a palindrome using different approaches.

---

## 🚀 Use Cases

### ✅ UC1 – Welcome Message
Displays application name and version at startup.

### ✅ UC2 – Hardcoded Palindrome
Checks whether a predefined string is a palindrome.

### ✅ UC3 – String Reverse Method
- Takes user input
- Reverses string using loop
- Compares using `equals()`

### ✅ UC4 – Character Array Method
- Converts string to `char[]`
- Uses two-pointer technique
- Efficient palindrome check

---

## ✅ UC5 – Advanced Palindrome Check

Checks whether a string is a palindrome while:

- Ignoring uppercase/lowercase differences
- Ignoring spaces
- Ignoring special characters

Example:
Input: "A man a plan a canal Panama"
Output: Palindrome

Concepts Used:
- String methods (replaceAll, toLowerCase)
- Regular expressions
- String processing
- Efficient comparison
